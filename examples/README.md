# Examples

Every folder here is a complete project: a `project.json`, a `build.py` that writes it deterministically
from the public services API, and a README. They are used three ways: they are the worked examples of
the methods, the application's start page and **Projects → Examples** import them, and the engine's
tests read them as fixtures.

## Worked examples of the methods (invented)

All names and figures are invented illustrations. None says anything about a real decision.

| Folder | What it shows |
| --- | --- |
| [`engineering_trade_study`](engineering_trade_study/README.md) | Every method on one model: MAVT with two profiles and a scenario, sorting classes, SMAA-2, PROMETHEE II, 78 AHP judgements and two requirements |
| [`flood_defence_options`](flood_defence_options/README.md) | A hard requirement beside every ranking, and PROMETHEE II beside MAVT |
| [`clinic_site_selection`](clinic_site_selection/README.md) | AHP pairwise judgements beside separately stated swing weights, with one inconsistent matrix |
| [`supplier_selection`](supplier_selection/README.md) | A compact procurement problem with every scale and value-function kind |
| [`supplier_qualification`](supplier_qualification/README.md) | The same suppliers sorted into ordered classes |
| [`infrastructure_procurement`](infrastructure_procurement/README.md) | Hierarchical swing weighting with an only child, a zero rating and two profiles |

## Venture material (real companies, public information)

These three folders are about real New Zealand startups, from public information, and each has its own
disclaimer. They are not investment advice and not a statement about any company, and there is no
affiliation with or endorsement by them. They belong to a separate application,
[venture-frame](https://github.com/spar473/venture-frame), which presents them as case studies; they are
kept here because the engine's tests use them as fixtures.

| Folder | What it is |
| --- | --- |
| [`nz_deeptech_vc`](nz_deeptech_vc/README.md) | The original four-company deep-tech study, the main regression fixture |
| [`nz_venture_screening`](nz_venture_screening/README.md) | Eight real startups rated from public information against written rubrics |
| [`nz_first_round_retrospective`](nz_first_round_retrospective/README.md) | Five companies rated as they stood around their first rounds; a look-back with draft ratings, not a validation study |
